# XV-Yamileth

## Opciones por URL

- `?hotel=1` muestra la sección de sugerencias de hotel.
- `?pases=1` muestra el bloque de pases de invitación.
- `?pase=2` establece el número de personas del pase.

Las secciones de hoteles y pases se ocultan si no se activa su parámetro
correspondiente. Los parámetros se pueden combinar, por ejemplo:
`?hotel=1&pases=1&pase=2`.
